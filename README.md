# 🧮 Calculadora de IMC - Web App

Uma aplicação web simples, moderna e responsiva para o cálculo do Índice de Massa Corporal (IMC), desenvolvida com tecnologias web padrão.

---

## 🚀 Funcionalidades

* **Cálculo Instantâneo:** Processa o peso e a altura informados em tempo real.
* **Classificação Clara:** Exibe a categoria do IMC de acordo com os padrões da OMS (Abaixo do peso, Peso normal, Sobrepeso, Obesidade I, II e III).
* **Design Responsivo:** Interface otimizada para funcionar perfeitamente em desktops, tablets e smartphones.
* **Validação de Entradas:** Garante que os campos não fiquem vazios ou recebam valores inválidos.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias nativas, garantindo leveza e alta performance:

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Estilização moderna, variáveis customizadas e design responsivo (Flexbox).
* **JavaScript (ES6+):** Lógica de cálculo, manipulação do DOM e tratamento de eventos.
